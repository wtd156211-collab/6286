# 现场记录（现象描述，口径以 README 为准）

- 运营习惯写中文倍数：`1.5 万`、`2 亿`；万/亿和数字之间有时带一个空格。
- 长度常写中文全称（`三公里`），英文缩写大小写不统一（`2KM`、`3Min`）。
- 单独的 `m`/`M` 在表里最容易错：既可能指米，也可能指分钟，人工翻译出现过挑错量纲。
- `3米2` 这类连写出现过两种读法：3.2 米、3 平方米，人工无法凭上下文判断。
- 千分位逗号有时只写一半，如 `12,34`，需要和正确千分位区分开。
- 区间两端可能一端省略单位，也出现过量纲不同（`1米~2千克`）和上下界写反。
- 空单元格、只有空格/全角空格的单元格在导出里都不少，统计时要单独算空值而不是拒绝。
