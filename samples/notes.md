# 现场记录（只描述现象，口径以 README.md 为准）

- 运营填表很随意：`1.5 万`、`2 小时`、`三公里`、`50%`、`百分之五十` 都出现过，程序原先一个都不认。
- `3米2` 这类连写最坑：有人当 3.2 米，有人当 3 平方米，曾经猜错被投诉，现在一律拒绝并列出两种含义。
- 短单位 `m`/`M` 两义（米 / 分钟），`5M` 这种谁也不敢拍板，按歧义拒绝。
- 千分位经常写歪：`1,23`、`12,34,56` 都见过，按歧义逗号拒绝，不猜。
- 区间写法五花八门：`3~5米`、`3到5千米`、`1000~2000米`、`1.5万到2万` 都有；也出现过 `5~3` 这种倒序。
- 全角数字、大写数字（壹佰）、`1e3`、正号 `+5` 都出现过，直接拒。
- 空行、纯空格行、Tab 加全角空格的行都存在，按空值处理，不算拒绝。
- 有人填过 `20000亿`，超出 10^12 上限，按越界拒绝；负数也一律拒绝。
